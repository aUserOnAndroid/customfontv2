# CustomFont
CustomFont can import custom fonts in GD!
## How To Use:
* import a .fnt *AND* a .png file.
* click apply.
* and it should be there!
## How To Get .fnt and Png Files
* If You Are Android, iOS, Linux or Mac, Use **[SnowB](https://snowb.org)**
* If You Are On Windows, Use **AngelCode BMFont** (I Don't Use Windows, You Have To Figure It Out Yourself)
